# CI/CD Final Project

## Project Name
CI/CD Pipeline Implementation Using GitHub Actions, Tekton, and OpenShift

## Project Description
This project demonstrates the implementation of a Continuous Integration and Continuous Deployment (CI/CD) pipeline for a Python application.

## Technologies Used
- Python
- GitHub Actions
- Flake8
- Nose
- Tekton Pipelines
- Red Hat OpenShift
- Git and GitHub

## Project Objectives
1. Automate code linting and unit testing using GitHub Actions.
2. Implement reusable Tekton tasks for cleanup and testing.
3. Build and deploy the application using OpenShift Pipelines.
4. Monitor pipeline execution and application logs.

## CI/CD Workflow
Source Code → GitHub Actions → Linting → Unit Testing → Tekton Pipeline → OpenShift Deployment

## Project Status
Initial repository setup. CI/CD implementation in progress.
